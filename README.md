# Salon Manager (Android APK)

Offline-first client & appointment manager for hair salon owners — **owner-only**,
no client-facing app, no Google Play Store required. Built with **Capacitor + React +
SQLite**, bilingual **English / Amharic**, and displays dates on the **Ethiopian
calendar**.

**Developed by Melaku Sisay.**

---

## What this app does

- Full CRUD client list with search and status filter (New / Returning)
- Fixed visit-frequency options: every 2 weeks / 1 month / 2 months / 3 months
- **Next Expected Date** is auto-calculated from Last Service Date + Frequency
- **Today** and **Tomorrow** tabs auto-surface clients due on those dates
- **Mark as Done**: updates last service date, recalculates next date,
  increments the loyalty cycle counter, and removes the client from
  Today/Tomorrow until their next cycle
- SMS reminders sent straight from the owner’s own phone number:
  - tries a **silent send** via Android `SmsManager` first
  - **automatically falls back** to opening the native SMS app pre-filled
    with the number + message if permission is denied or the send fails
  - message is editable before sending; sent/not-sent status is tracked per client
- CSV **import** (matches common KoboCollect/KoboToolbox export headers)
  and CSV **export** for backups
- 100% offline — SQLite database on-device, no server, no login
- Rebrandable in one file (`src/theme/branding.ts`) plus an in-app
  Settings screen (salon name + primary color, no code change needed)

> **Why is there no `android/` folder here?** Capacitor generates the native
> Android project from your machine (it needs your local Android SDK paths).
> You generate it once with a single command — see `docs/BUILD_APK.md`.
> Everything it needs (the custom SMS plugin, permissions, icons) is already
> wired up to be picked up automatically.

## Quick start

```bash
npm install
npm run dev          # preview the UI in a browser (uses a web SQLite fallback)
```

To get the real, installable `.apk` **without installing anything**, push
this repo to GitHub — `.github/workflows/build-apk.yml` builds it for you
automatically and hands you the file from the Actions tab. Or build it
locally by following **`docs/BUILD_APK.md`** (a copy-paste, ~10 command
process using free tools: Node.js + Android Studio).

To install the finished APK on your phone, follow **`docs/INSTALL_APK.md`**.

To push this project to your own GitHub repository, follow
**`docs/GITHUB_SETUP.md`**.

To rebrand this app for a different salon, follow **`docs/REBRANDING.md`**.

## Design notes

- **Data model**: dates are stored internally as Gregorian ISO (`YYYY-MM-DD`)
  for reliable date arithmetic, and converted to Ethiopian dates *only* for
  display (`formatEthiopian()`), since that is what the app shows the owner
  everywhere in the UI.
- **SMS**: implemented as a small custom native Capacitor plugin
  (`plugins/salon-sms`) because Capacitor’s official plugin set does not
  expose Android’s silent `SmsManager` API — community "SMS" plugins only
  open the SMS app. This plugin gives you both behaviors described in the
  spec (Option B primary, Option C fallback) in a single call.
- **Offline-first**: `@capacitor-community/sqlite` gives a real on-device
  SQLite database (not IndexedDB/localStorage), so it performs well even
  with thousands of clients and needs no network connection ever.
